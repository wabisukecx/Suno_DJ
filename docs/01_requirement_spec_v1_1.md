# VCI-100 AI DJ Mixer - 要件定義書

**バージョン**: 2.0  
**最終更新日**: 2026-02-02  
**プロジェクト**: VCI-100 AI DJ Mixer  
**ステータス**: Phase 9G (Auto-Analysis) + Phase 8L (4-Bar Loop) 実装完了

---

## 1. プロジェクト概要

### 1.1 目的

Vestax VCI-100 MIDIコントローラーとAI技術(Suno AI, Google Gemini)を組み合わせた次世代DJミキシングシステムの開発。DJのクリエイティブワークフローを支援し、「endless, yet always fresh DJ sets」を実現する。

### 1.2 背景

**現状の課題**:

- DJ用楽曲ライブラリの拡充には膨大な時間とコストが必要
- セット中の次曲選択・準備が演奏の流れを妨げる
- レガシーハードウェア (VCI-100) が現代PC環境で十分活用されていない
- 楽曲解析作業(BPM/Key/Energy)が手作業で非効率

**解決アプローチ**:

- AI音楽生成 (Suno) と組み合わせ、演奏中の楽曲から最適な次曲を生成するプロンプトを自動提案
- 高精度な楽曲解析とキャッシング機構により、ライブラリ管理を効率化
- 4小節ループ機能により、ミックス作業を支援

### 1.3 スコープ

#### 対象範囲 (Phase 9G時点)

✅ **実装済み**:

- VCI-100 MIDIコントローラー完全統合 (66個のMIDI CCマッピング)
- リアルタイムオーディオ再生・ミキシング (BASS Library統合)
- デュアルデッキ再生 (Deck A/B同時制御)
- 3バンドEQ (Low/Mid/High, DirectX8 ParamEQ)
- クロスフェーダー (等電力カーブ)
- LPF/HPFフィルター
- Tempo/Pitch制御 (BASS_FX)
- 4小節ループ機能 (BASS_SYNC_MIXTIME)
- 楽曲解析 (BPM, Key, Energy, Genre) + キャッシュ機構 (v4)
- 自動解析機能 (未解析トラック一括処理)
- AI プロンプト生成 (Google Gemini 2.0 Flash)
- ホットフォルダ連携 (Suno DL自動取り込み)
- Energy Flow可視化 (鏡像配置パネル)
- 波形表示 (Min-Max Decimation)
- ライブラリ管理 (ソート、カーソル移動、ダブルクリックロード)
- BPM手動修正機能

#### 対象外

❌ **将来実装**:

- Suno APIとの直接統合 (現状: 手動コピー&ペースト方式)
- 波形編集機能
- 高度エフェクト (リバーブ, ディレイ, フランジャー等)
- レコーディング機能
- ビートグリッド編集
- Cue Point設定

## 3. 機能要件

### 3.1 オーディオ再生・ミキシング (F-01)

#### F-01-01: デュアルデッキ再生 ✅

- **説明**: Deck A/B の2チャンネル同時再生
- **優先度**: 必須
- **実装状況**: 完了
- **詳細**:
  - サポート形式: MP3, WAV, FLAC
  - サンプルレート: 48kHz自動変換
  - レイテンシ: 11.6ms (実測値, 目標 <15ms)
  - 自動ゲイン補正 (Auto Gain) ※実装予定

**検証基準**:

- [ ] 2トラック同時再生が途切れなく動作
- [ ] レイテンシが15ms未満

#### F-01-02: クロスフェーダー ✅

- **説明**: Deck A/B 間のボリューム連続調整
- **優先度**: 必須
- **実装状況**: 完了
- **詳細**:
  - カーブタイプ: Constant Power (cos/sin)
  - 範囲: 0.0 (Full A) 〜 1.0 (Full B)
  - セーフスタート: 起動時は初期フェーダー位置を無視
  - MIDI CC: VCI-100 Crossfader (CC#8)

**検証基準**:

- [x] 中央位置で両デッキが同音量 (パワー一定)
- [x] セーフスタート有効時、起動直後は音が出ない

#### F-01-03: 3バンドEQ ✅

- **説明**: High/Mid/Low 独立EQ調整
- **優先度**: 必須
- **実装状況**: 完了
- **詳細**:
  - 実装: DirectX8 ParamEQ (BASS_FX未対応時のフォールバック)
  - 周波数帯域:
    - Low: 100Hz (18.0 bandwidth)
    - Mid: 1000Hz (18.0 bandwidth)
    - High: 8000Hz (18.0 bandwidth)
  - ゲイン範囲: -15dB ~ +15dB (safe clipping)
  - Deck A/B 独立制御

**検証基準**:

- [x] 各バンドが独立して動作
- [x] ±15dBの範囲で音質劣化なし

#### F-01-04: アイソレーターフィルター ✅

- **説明**: LPF/HPF切り替えフィルター
- **優先度**: 高
- **実装状況**: 完了
- **詳細**:
  - 実装: BASS_FX_BFX_BQF (双2次フィルター)
  - LPF範囲: 20kHz (center) → 100Hz (full)
  - HPF範囲: 20Hz (center) → 15kHz (full)
  - MIDI CC: VCI-100 Filter Knob (CC#23/27)

**検証基準**:

- [x] LPF: 高音域が滑らかに減衰
- [x] HPF: 低音域が滑らかに減衰

#### F-01-05: マスターボリューム ✅

- **説明**: 最終出力ボリューム調整
- **優先度**: 必須
- **実装状況**: 完了
- **詳細**:
  - 範囲: 0.0 〜 1.0
  - MIDI CC: VCI-100 Master Volume (CC#24)

**検証基準**:

- [x] 全体音量が連続的に調整可能

## 5. 制約条件

### 5.1 技術的制約

- **BASS Library**: 商用利用には有料ライセンス必要 (個人利用は無料)

### 5.2 運用的制約

- **インターネット接続**: Prompt生成時に必須
- **MIDI Controller**: VCI-100実機が必要 (エミュレート不可)
- **音声出力**: ASIO/WASAPIドライバー推奨 (低レイテンシ)

## 9. 用語集

| 用語 | 説明 |
| ---- | ---- |
| **BPM** | Beats Per Minute (テンポ) |
| **EQ** | Equalizer (周波数帯域ゲイン調整) |
| **LPF** | Low-Pass Filter (高音域カット) |
| **HPF** | High-Pass Filter (低音域カット) |
| **Crossfader** | 2チャンネル間の音量連続調整フェーダー |
